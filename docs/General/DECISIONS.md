# Decision Log

Every architectural and product decision in the project, in one place, so
"why did we choose X" is queryable rather than buried in chat history or PR
descriptions.

**This is the index, not the source.** Each decision also appears in the doc
that owns its subject, with the surrounding reasoning. Where a decision is
listed in more than one doc, the ID is the same in all of them — cite the ID,
not the row number.

- **locked** — settled. Revisit only with a strong reason and a note here.
- **open** — recorded but not decided. Someone has to choose.

| D136 | **The deck learns from a swipe: a per-cuisine like rate, shrunk toward the onboarding pick.** The taste term asked one question — is this cuisine one of the ones picked during onboarding — so a user who picked a cuisine and has passed on it ever since kept getting it, and every swipe that said otherwise went nowhere. It now scores `0.60 × (likes + 2 × prior) / (swipes + 2)` per cuisine. **The prior is a degenerate 1.0 and 0.0 on purpose**: the softer 0.65 and 0.35 spans 0.045 of the total score, inside the jitter's shadow even after D137 halved it, so the onboarding pick would have quietly stopped mattering the day this shipped. | D137 | **Deck diversity is a soft per-position penalty, and the jitter halves behind it.** `get_deck` could deal five satay stalls in a row: proximity dominates, satay stalls cluster geographically, and the jitter is per restaurant rather than per position, so it could only make the run a different run each day. | D138 | **A place that is shut ranks like it: ±0.08, and never a filter.** `deck_scored` already resolved the local hour in Asia/Kuala_Lumpur and spent it on the morning-mode nudge alone; `is_open_at` already answered the question for `get_nearby`, past-midnight and closed-weekday cases included, and `opening_hours.dart` asks it the same way on the device (D92). | D139 | **A pass comes back gently: the three-day floor stays hard, and above it the score decays in.** Deck exhaustion resurfaces a pass older than three days, and it used to come back at exactly the score it left with — a place passed on Monday and one passed in March were the same card to the ranker. The floor stays a hard `where` rather than becoming part of the curve, because a decayed score near zero would ride the jitter back to the top of a thin deck. Only bucket 1 is touched and bucket 0 always sorts first, so a deck that is not exhausted is byte-identical — proved by hash on two argument sets.
